The browser calls Next.js App Router pages and API routes under `src/app/`. Server-side domain modules under `src/modules/` own workflow rules, PostgreSQL access, Azure DevOps and LLM calls, workspace authorization, and project isolation. Shared UI and infrastructure live under `src/components/`, `src/lib/`, and `src/shared/`; `src/worker/` processes background jobs. Credentials remain server-side and generated AI outputs pass through human review before Azure DevOps writes.
