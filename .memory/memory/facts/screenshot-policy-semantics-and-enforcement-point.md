screenshot-policy.ts defines every-step | validation-points (default) | failures-only | none. A validation point is a step with a non-empty expected result. validation-points also captures failure evidence on any non-passed step; cancelled steps never capture. Enforcement is deterministic in the playwright-execution-job step loop (after executeTestStepWithAgent resolves and in the step catch, while the MCP connection is still open) via browser_take_screenshot + importInlineMcpArtifacts, try/caught so capture failure never changes the step outcome. Policy none additionally passes persistInlineScreenshots:false so agent-initiated inline images are not persisted either. The job also navigates to the run's base URL before each case's first step, policy-validated; a disallowed origin fails the case with a friendly error instead of aborting the run.
