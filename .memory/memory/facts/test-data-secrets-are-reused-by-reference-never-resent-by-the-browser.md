playwright_execution_run_data and playwright_execution_profile_data store title/value rows; secret rows hold an AES-GCM quad (encrypted_value/value_iv/value_tag/value_key_version) with an XOR CHECK against plaintext value. Reruns and profile prefills send {title, isSecret:true, fromRunId|fromProfileId, sourceTitle?}; the server copies the encrypted quad verbatim after a workspace+project ownership check (resolveTestDataEntries in execution-test-data.service.ts). Detail routes return secrets metadata-only. Profile updates use a bare {title, isSecret:true} row to mean keep-saved. Decryption happens only in the worker, and decrypted secret values are threaded into execution-redaction (exact-occurrence scrub, min length 4) for every persisted transcript and error.
